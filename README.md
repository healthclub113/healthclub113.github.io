# HEALTH CLUB 113

Готовый репозиторий для GitHub Pages.

## Куда загрузить
Создайте публичный репозиторий с точным именем:

`healthclub113.github.io`

Загрузите всё содержимое этой папки в корень ветки `main`.

После публикации:
- Главная: https://healthclub113.github.io/
- Тест: https://healthclub113.github.io/test-energii/
- Корзина: https://healthclub113.github.io/korzina.html

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root)

## После запуска
1. Исправить старую ссылку `juliahealth113.github.io/test-energii/` в описании репозитория.
2. Отправить новые адреса боту @WebpageBot для обновления Telegram-превью.
3. Проверить цели счётчика Яндекс.Метрики 110504158.
4. Папка `ai` не включена, потому что её исходники не были переданы.
